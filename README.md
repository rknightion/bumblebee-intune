# bumblebee-intune

Reference Microsoft Intune deployment for Bumblebee: configuration profiles, policies, and the
deployment guidance that goes with them.

**Status: placeholder.** The repository exists and is wired into CI and the docs fleet, but the
reference content has not landed yet. Every documentation page currently says TBC.

Documentation: <https://m7kni.io/bumblebee-intune/>

## What will live here

- Configuration profiles and policy definitions for a reference Bumblebee tenant
- Deployment guidance: assignment strategy, ring rollout, and what to verify at each stage
- Code samples for provisioning and reporting against the deployment

## Layout

| Path | Contents |
| --- | --- |
| `docs/` | The published documentation site source. Built and deployed by the [m7kni.io hub](https://github.com/rknightion/m7kni-net-site), not by this repo. |

## Contributing

The published site is built centrally. This repo owns `docs/**/*.md` and `docs.toml` and nothing
else about the site — `zensical.toml`, the brand stylesheet, the SEO template, the fonts and the
social card are injected by the hub at build time and are gitignored here. A tracked copy of any
of them is drift.
